# Assignment 2 — Static E-commerce Website

## Reference Website

**Site:** Nike  
**URL:** https://www.nike.com/

The design of this assignment is inspired by Nike's simple product cards, dark buttons, clean navigation, and sportswear layout. A screenshot of the reference site should be added below for the completion PDF:

![Nike reference website screenshot](reference-screenshot.png)

## Pages

- `index.html` — responsive homepage and product listing with eight product cards
- `product.html` — responsive Air Max 90 product detail page
- `style.css` — shared CSS using CSS Grid, Flexbox, and media queries

The site is static HTML and CSS only. The navigation, search field, quantity selector, and cart buttons are present for layout practice and are not functional.

## Responsive design

The layout uses media queries for desktop, tablet, and phone widths. The product grid displays four columns on desktop, three on tablet-sized screens, and two on phone-sized screens. The product detail layout changes from two columns to one column on smaller screens.
